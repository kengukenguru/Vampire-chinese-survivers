# Vampire Chinese Survivors 🧛‍♂️

Полнофункциональная казуальная RPG-игра в стиле Vampire Survivors с персонажами и врагами из китайской мифологии.

## 🎮 Особенности

- **4 уникальных персонажа** с разными стилями боя
- **Враги из китайской мифологии** (обычные и боссы)
- **Система способностей и оружия** с синергиями
- **Пассивные баффы** для кастомизации геймплея
- **Поддержка мобильных устройств** (сенсорное управление)
- **Система волн и уровней сложности**
- **Сохранение прогресса**

## 📋 Требования

- Godot 4.6.3+
- Разрешение экрана: 1280x720 (PC) / 720x1280 (мобильное портретное)

## 🚀 Быстрый старт

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/kengukenguru/Vampire-chinese-survivers.git
   ```

2. **Откройте в Godot 4.6.3:**
   - Запустите Godot
   - Выберите "Import" → выберите папку проекта
   - Нажмите "Import & Edit"

3. **Запустите игру:**
   - Нажмите F5 или кнопка "Play"

## 👹 Враги

### Обычные враги:
- **Цзюаньцюй** - духи-призраки (слабые, быстрые)
- **Ямалуки** - демоны (средние, сильные)
- **Кицунэ** - духи лис (быстрые, хитрые)
- **Юйлин** - морские духи (средние)

### Боссы:
- **Нэчжа** - небесный генерал
- **Щитник** - король подземелья
- **Королева Жэньхуан** - верховная королева насекомых
- **Драконий Синь** - восточный небесный дракон

## 🎮 Управление

### PC:
- **WASD / Стрелки** - движение
- **Мышь** - наведение на врагов
- **Пробел** - активная способность (на выбор)
- **E** - меню паузы

### Мобильное:
- **Движение по касанию** - движение персонажа
- **Кнопки на экране** - активные способности
- **Меню сенсорное** - выбор персонажа и способностей
